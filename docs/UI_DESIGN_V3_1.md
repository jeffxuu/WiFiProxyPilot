# v3.1 UI 与交互规范

保留 .NET 8 WinForms，使用 Windows 11 Fluent 的浅色背景、蓝色主操作、白色信息卡片、固定导航和统一间距作为参考；没有引入额外运行环境。字体 Microsoft YaHei UI，AutoScaleMode=Dpi。EXE 使用 16–256px 多尺寸 Wi-Fi 图标，托盘使用同一图形及状态颜色。

| 页面 | 内容 | 常用操作 |
| --- | --- | --- |
| 概览 | 简短主状态、六张卡片：SSID、网关、手动代理、规则、检测时间、代理服务诊断 | 开启/暂停、立即检测、名单管理、详细信息 |
| 免代理 Wi-Fi | 完整名称列表，内置项标记，输入及当前 SSID 添加 | 添加、删除所选、保存并应用、取消修改/重新载入 |
| 设置 | 四项日常偏好；模式、端口、轮询、TCP/HTTP/None 诊断及 HTTP URL | 保存设置；高级区修复/升级、恢复、卸载 |
| 日志与诊断 | 有界 JSONL 尾部解析，本地中文可读时间，事件、Wi-Fi、目标、原因及错误 | 错误过滤、原始 JSON 切换、刷新、复制、打开目录 |

首次绘制不等待资源解包、安装或 PowerShell 进程。首次安装由用户操作触发并确认。普通成功反馈写入底部状态栏；错误和高风险操作用明确对话框。状态更新只改现有控件属性，不重建页面。所有数据读取、完整性检查和控制脚本调用离开 UI 线程。

关闭按钮默认隐藏到托盘；取消此设置后 X 只退出界面，监控仍独立运行。窗口忙时可隐藏，但禁止退出和第二次操作。主界面、设置保存和托盘命令共享 busy 状态；立即检测只在监控运行且未暂停时可用。

SSID 不 Trim；大小写去重使用 OrdinalIgnoreCase。内置规则不可删除。添加当前连接使用原有 Native WLAN 读取器，夹读两次、检查接口/字节身份和事件代数；权限、过渡状态、多个接口或非法 UTF-8 时拒绝猜测。普通手动输入仍可使用合法中文名称。

名单和设置分别维护草稿。保存一页不偷偷提交另一页草稿。外部修改导致 revision 冲突时拒绝覆盖，使用“重新载入”取回有效配置。保存确认仅表示持久化成功；收到对应 ConfigRevision 且稳定代理目标一致后才提示后台重新评估完成。暂停时保存配置不修改代理。

长值单行省略并提供 Tooltip/详细信息，日志可双向滚动；设置页可滚动，避免小屏幕与高 DPI 裁切。支持默认 WinForms Tab/Shift+Tab 导航；名单输入支持 Enter 添加。已生成并人工检查 100/125/150/200% **合成缩放**截图；真实跨显示器 DPI 与 Windows 设置中的 DPI 切换仍需人工验收。
