The project's MIT license applies to project source; it does not replace dependency licenses or font restrictions.

## Current UI direction

The intended v3.2 interface uses custom WPF templates and project-owned vector drawings. WPF-UI 4.3.0 was evaluated: its official package includes compatible .NET 8 assets and a MIT license. The current design direction does not require its default controls or icon fonts. Evaluating the library is not a claim that it is a final shipped dependency. The final build's project references and package contents decide that status.

The evaluated package's unmodified notices are preserved in [WPF-UI-LICENSE.md](licenses/WPF-UI-LICENSE.md) and [WPF-UI-ThirdPartyNotices.txt](licenses/WPF-UI-ThirdPartyNotices.txt). They include MIT components and a separate Segoe Fluent Icons font restriction that does not grant redistribution rights. Do not copy Windows font files into a release under the project's MIT license.

## Runtime and assets

- .NET 8/WPF self-contained runtime: .NET Foundation/Microsoft license and notices apply to the bundled runtime.
- Windows Segoe UI/system fonts: used as installed Windows resources; separately copied font redistribution rights are not granted by this project.
- Product icon: project geometric drawing generated by `tools/Generate-Icon.ps1`; no Apple artwork copied.
- UI vector assets: project-owned paths/templates; check the final code/assets before publishing.
- Screenshots: actual software running in an isolated fixture, clearly marked as simulated data.

Upstream references: [WPF UI](https://github.com/lepoco/wpfui), [evaluated NuGet package 4.3.0](https://www.nuget.org/packages/WPF-UI/4.3.0), [.NET license](https://github.com/dotnet/runtime/blob/main/LICENSE.TXT).
