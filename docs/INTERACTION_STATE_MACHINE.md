# 应用状态与操作语义

v3.2 的状态分为四个独立维度。主状态表达软件管理情况，网络和诊断保留独立状态，避免把“代理已开启”误当作“网络已经可用”。

## 状态来源

| 维度 | 来源 | 取值 |
| --- | --- | --- |
| 用户管理意图 | `config.json` 的 `ManagementIntent` | `Monitoring`、`Paused`、`Direct` |
| 应用主状态 | `ApplicationStateEvaluator` 根据安装、首次设置、引擎兼容、策略和心跳评估 | 下表八种状态 |
| 当前网络 | WLAN 与关联 IPv4 路由的实际读取结果 | Unknown、Connected、Disconnected、NoWirelessAdapter、AccessDenied、WlanUnavailable、DhcpPending、GatewayUnavailable、Ambiguous |
| 手动代理 | 当前用户 Windows 手动代理读回 | 开启/关闭、地址、PAC/自动检测提示、外部变更 |
| 代理诊断 | 独立 Watcher 的检测及时间 | Unknown、TcpReachable、HttpValidated、Failed、Disabled |

`SetupComplete=false` 的配置只能保持暂停。新用户在引导中确认后才完成设置并启动安装/管理。旧配置迁移视为已设置，保留原有使用习惯。

## 主状态

| 状态 | 条件 | 显示及操作 |
| --- | --- | --- |
| NotInstalled | 没有当前用户安装记录 | 说明产品并进入首次设置 |
| UpgradeRequired | 已安装，但配置或后台引擎不兼容 | 要求升级后台；不确认新规则已应用 |
| SetupRequired | 已安装但首次设置未完成 | 继续引导；自动写入被禁止 |
| PolicyManaged | 组织策略阻止管理 | 说明 Windows 管理限制，展示只读状态 |
| DirectMode | 用户意图为 Direct | 说明自动切换暂停，并独立展示当前手动代理实际状态 |
| Paused | 用户意图为 Paused | 说明当前代理可能仍生效；允许重新开启 |
| Degraded | 意图为 Monitoring，但后台停止、心跳陈旧或读取失败 | 展示原因、上次成功时间和可执行建议 |
| Monitoring | 意图为 Monitoring，兼容后台运行且有新鲜有效状态 | 显示规则与代理实际结果 |

判断优先级按表从上到下。暂停和直连不会被陈旧心跳覆盖成“运行中”；读取失败仍应通过独立错误提示显示。网络没有连接、没有有效网关、诊断未知都不得用绿色正常状态掩盖。

## 操作契约

| 用户操作 | 意图/后台行为 | Windows 手动代理 | 备份 |
| --- | --- | --- | --- |
| 开启自动切换 | 持久化 Monitoring，启动归属任务或唤醒已有 Watcher；废弃旧稳定状态 | 当前网络经稳定确认后按规则写入 | 保留最初备份 |
| 暂停自动切换 | 持久化 Paused；后台停止自动写入，可继续只读观察 | 保留当前设置；明确提示可能仍生效 | 保留 |
| 恢复直连 | 持久化 Direct，阻止自动重启代理，然后进行一次关闭操作 | 仅关闭手动代理；保留地址、绕过项及 PAC/自动检测 | 保留；记录自身最后写入 |
| 恢复安装前配置 | 先暂停/停止自动管理，再按原有冲突保护恢复 | 当前配置等于原始或最后自身写入时恢复；冲突默认拒绝覆盖 | 使用最初备份 |
| 立即检测 | 发送检测请求，重新采集网络并经过防抖；暂停/直连不会因此恢复自动写入 | 根据持久化意图处理；不使用缓存旧网关强制写入 | 保留 |
| 保存并应用规则 | revision 检查后原子替换配置；Watcher 热加载、废弃旧诊断/防抖 | 按意图和新规则稳定评估 | 保留上一份有效配置 |
| X 关闭窗口 | 默认隐藏主窗口、保留托盘 | 不写入 | 不变 |
| 退出界面 | 释放 GUI/托盘句柄和订阅；独立 Watcher 继续 | 不写入，不恢复 | 不变 |
| 彻底卸载 | 停止自有 Watcher，验证任务/文件归属，安全恢复并清理 | 冲突默认保留，不覆盖用户后续修改 | 成功流程按原有保护处理 |

暂停、直连和配置写入使用同一配置锁；Watcher 在最终写入前重读管理意图。按钮即时显示处理中，实际结果读回后更新状态。失败信息要说明哪个步骤完成，不能把持久化意图失败或代理关闭失败显示为成功。

## 退出、锁屏、注销和重启

`ManagementIntent` 持久化，不由窗口生命周期决定。GUI 再次启动只读取意图；不自动安装、开启或恢复代理。锁屏不改变意图，解锁与休眠唤醒请求刷新；Watcher 遇到长时间间隔废弃旧诊断与防抖，重新采集。注销结束用户进程；下一次登录是否启动 Watcher/托盘分别由 `LoginMonitor`/`TrayAutoStart` 决定，启动后继续遵守 Paused 或 Direct。Direct 只代表不再自动写入；外部程序后来重新开启手动代理时，界面显示实际结果，不反复覆盖外部变更。

## 新鲜度与应用确认

每次状态读取记录检测时间。失败或心跳超时显示“暂时无法读取”及上次成功检测时间。陈旧的 SSID、网关和诊断必须标记旧数据，不当作实时状态。

保存成功仅证明 JSON 写入成功。后台报告兼容 SchemaVersion、对应 `ConfigRevision` 和 `AppliedRevision`、`Stable=true` 且心跳新鲜时，才显示“规则已应用”。未稳定、旧引擎、暂停观察未确认或后台不可达时显示“已保存，等待后台应用”。TCP 连通只证明端口可连接；HTTP 代理验证必须有实际代理请求结果。Strict 不因探测失败关闭代理；Safe 达到连续失败阈值后可能回退直连，并明确说明部分流量可能不经过代理。

真实登录、休眠、Explorer 恢复和关闭窗口后的网络行为属于本机待授权验收，不能仅凭事件处理代码宣称通过。
