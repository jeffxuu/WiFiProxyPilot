# EXE 本机验收：Windows 11 x64

Linux 构建和模拟不能证明这些场景通过。GitHub Windows runner 的 EXE 渲染冒烟测试只能验证启动、依赖打包和 WinForms，不会连接真实 Wi-Fi 或改系统代理。

| 场景 | 本机操作与验收 |
|---|---|
| 1 启动 | 双击 EXE，出现中文状态窗口；关闭窗口后 Watcher 继续。任务登录时只运行隐藏引擎，不出现 GUI |
| 2 首次安装 | 下载到中文/空格路径，用当前账户首次右键管理员运行；核对开始菜单、已安装应用、原代理备份、当前 SID 的有限权限登录任务及新心跳 |
| 3 重复安装 | 修改 installed config 后从同版/新版 EXE `/install`；配置和首次备份不变，任务和 Watcher 各一个 |
| 4 卸载 | 状态窗口“卸载”或 Windows 已安装应用卸载；原窗口关闭后独立卸载器完成。检查无任务/Watcher/开始菜单/卸载项，原代理恢复；默认保留日志与用户改动 |
| 5 中文路径 | 源 EXE、Windows 用户名和自定义 `/install-dir` 使用中文；SSID 与日志不乱码 |
| 6 空格和特殊符号 | 测试空格、`!`、`&`、方括号；任务计划程序会展开的成对 `%NAME%` 安装目录应明确拒绝 |
| 7 普通用户 | 普通会话安装/启动/停止/恢复；权限被组织策略禁止时显示具体错误，不自动提权或改策略 |
| 8 管理员 | 同一用户提权允许；借用另一个管理员的凭据运行应明确拒绝。任务必须 Limited + Interactive，HKCU 属于桌面用户 |
| 9 参数 | `/install /status /restore /uninstall /start /stop /check`；未知参数失败；`/status /output "路径"` 生成只读诊断；GUI 子进程无控制台闪烁 |
| 10 异常恢复 | 在测试环境终止本工具 Watcher，任务约一分钟重启；人为阻塞文件复制/删除后能重试，不丢首次备份；不杀其他进程 |
| 11 配置冲突 | 停止后手工修改代理，再恢复或卸载；分别验证恢复/保留/取消。`/quiet` 无明确 force/keep 必须保留配置并返回冲突记录 |
| 12 立即检测 | PollSeconds=300 时点击立即检测，Watcher 在分段等待后读取新状态，仍经过防抖且不使用旧网关 |
| 13 引擎功能 | 继续完成 WINDOWS_ACCEPTANCE.md 的全部 SSID、网关、Strict/Safe、PAC、权限、休眠/登录及 24 小时矩阵 |

`/uninstall` 会把工作交给临时卸载器，以便删除正在运行的已安装 EXE。初始进程退出码 10 表示“已交接”，不是完成；最终结果位于 `%LOCALAPPDATA%\WiFiProxySwitcher-Control\uninstall-result.json`，非静默模式同时显示完成/失败提示。卸载器不终止无关进程，等待原窗口最多 45 秒。其他仍开着的旧版窗口会导致文件锁错误，关闭后从原下载 EXE 重试即可。

临时卸载 EXE 位于同一 Control 目录的 uninstall-helper；正在运行时不能删除自身，退出后可手动删除此目录（后续卸载会清理超过一天的旧副本）。这是无自启行为的缓存文件，不是残留任务。源下载 EXE、用户修改文件和默认保留日志也不会被自动删除。
