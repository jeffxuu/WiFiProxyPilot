## 本机验收授权边界

默认检查使用隔离目录和模拟网络。以下操作等用户明确授权后执行：真实安装升级、代理写入/直连/恢复、任务安装卸载、登录自启验证、休眠/唤醒、Explorer 重启和网络切换。操作前记录当前值与最初备份位置，保留原始账户、文件归属和冲突保护。

真实验收清单至少记录：操作、预期、实际、是否通过、未验证原因。只读采集可记录关闭窗口前后 GUI/Watcher PID、心跳、新旧网关、代理值、TCP/HTTP；不能凭 X 隐藏成功就判定真实断网问题已修复。
