# WiFi Proxy Pilot 产品要求

版本：v3.2.0-beta.1。目标平台：Windows 11 x64，当前交互用户。

本工具根据 Wi-Fi 网络自动切换 Windows 手动代理。它不自带 VPN、代理服务器或流量加密服务；系统代理开启不代表已经能够访问互联网。

当前先交付实际 WPF 视觉初版供用户确认：采用简洁的 macOS 信息层级与自定义控件模板，适配 Windows 的键盘、托盘和窗口习惯，不复制 Apple 素材。WPF UI 4.3.0 已评估，但不要求引入其默认控件或图标字体；最终依赖以实际项目为准。公开发布准备仍为草稿，不能据此宣称第三阶段完成。

## 用户场景

| 场景 | 用户需要 | 产品行为 |
| --- | --- | --- |
| 手机热点共享代理 | 手机提供代理，电脑连接热点 | 重新采集当前物理 Wi-Fi 接口的 IPv4 默认网关，加上用户端口；换网后重新确认 |
| 家庭与办公网络切换 | 一些网络直连，其他网络使用代理 | 用户管理全部免代理 Wi-Fi 规则，完整名称忽略大小写匹配 |
| 第一次使用 | 理解作用并自主决定是否启用 | 解释产品、设置端口、添加可选规则、确认修改 Windows 手动代理后才启用 |
| 日常后台使用 | 关闭窗口后继续工作 | UI、托盘与独立 Watcher 分离；X 默认隐藏，退出界面不停止后台 |
| 网络异常 | 看懂问题并恢复联网 | 分开显示管理意图、Wi-Fi、系统代理及诊断；提供暂停、直连和安全恢复 |

## 发布门槛

1. 新用户默认 `Whitelist: []`。全部名称可新增、编辑、删除，空名单可保存。旧用户升级保留实际安装名单，不清空、不自动补回旧规则。
2. 名称按 `OrdinalIgnoreCase` 完整匹配；1–32 个 UTF-8 字节；拒绝控制字符；保留合法空格。网络切换不能混用旧网关。
3. 自动监控、暂停和直连意图持久化在配置中，UI 和 Watcher 使用同一来源。窗口打开、锁屏、注销、重启不自动取消用户选择。
4. 暂停只停止后台代理写入。直连先暂停自动管理，再仅关闭手动代理。恢复使用最初备份并保留冲突保护。PAC、自动检测等无关设置不被擅自修改。
5. 首页三秒内说明：是否自动管理、当前 Wi-Fi、手动代理状态、规则原因及故障操作。主要操作为自动切换、立即检测、Wi-Fi 规则；低频操作进入设置。
6. “配置已保存”与“规则已应用”分开。后台版本兼容、revision 一致、当前网络稳定确认且心跳新鲜后才能确认应用。
7. 首次启动不修改开发机或用户代理。旧引擎不能识别新意图时显示需升级后台，避免把旧引擎视为已支持新配置。
8. 安装身份、路径、最初备份、任务名、锁和卸载记录继续兼容。卸载仅清理属于产品且符合清单/哈希/账户保护的文件和任务。
9. 正式 GUI 使用 WPF 展示层和独立应用服务。视图不承担 PowerShell、注册表、WLAN、任务或原子保存业务。
10. 所有发布声明必须有实际证据。隔离模拟测试和 UI 自动化不能替代真实 Windows 网络、任务、休眠或恢复验收。

## 性能目标

| 项目 | 目标 | 比较方式 |
| --- | --- | --- |
| 驻留托盘打开窗口 | 优先 ≤200 ms | 包含实际绘制，区别于重新启动 EXE |
| 热启动首次可交互 | 优先约 1.2 s 或更快 | 同机同条件测量，记录真实样本及限制 |
| 操作响应 | 尽量 100 ms 内有反馈 | 长操作显示忙碌反馈，后台异步执行 |
| 状态与日志 | 无持续 UI 冻结 | 限制日志读取、禁止定时器重入、最小 Dispatcher 更新 |
| 常驻资源 | 无明显持续 CPU 占用 | 有代表性的空闲和刷新采样，注明观察时长 |

v3.2 实测及测量限制以 `PERFORMANCE_V3_2.md` 为准，目标值不作为通过证据。

## 本轮范围与后续

本轮保留网关目标、Strict/Safe、WLAN/WinINet、原始备份、热更新及安全缓存。固定代理地址策略属于后续功能，若未实现不得宣传。仓库以 WiFiProxyPilot 公开展示，版本为 v3.2.0-beta.1；真实验收限制继续公开说明。

实现结果见 `TEST_RESULTS_V3_2.md`；状态语义见 `INTERACTION_STATE_MACHINE.md`；升级步骤见 `CONFIG_MIGRATION.md`。
